Documentação Técnica

Visão geral

Esta versão do site inclui otimizações de imagens, uma página de relatório com gráficos e um pipeline de build com Vite. Também há integração de CI para deploy contínuo via GitHub Actions.

Otimização de imagens

  • Conversão automática para WebP.
  • Geração de variações responsivas: 320, 640, 1024, 1600 (quando aplicável).
  • Placeholder em base64 gerado para carregamento progressivo.

Build (Vite)

Há um scaffold Vite em /webapp. Comandos:

npm install
npm run dev   # desenvolvimento
npm run build # gera /webapp/dist

CI / Deploy

O workflow GitHub Actions (.github/workflows/ci.yml) faz:

  1. Instala dependências Node
  2. Executa build (npm run build)
  3. Publica conteúdo de /webapp/dist para a branch gh-pages

Para que o deploy funcione automaticamente, configure o secret GH_PAT (opcional — o action usa o token do GitHub por padrão).
